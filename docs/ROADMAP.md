# Roadmap

Waylit is built in phases. Only milestone 1 (phases 0 to 2) is planned in detail. Later phases are outlined and will be detailed once the 3D prototype proves the experience on real phones.

Status key: **done**, **in progress**, **planned**.

| Phase | Name | What it delivers | Status |
|---|---|---|---|
| 0 | Open source foundation | Licence, community files, CI, contribution and deployment docs, a run-with-no-keys rule | in progress |
| 1 | PWA foundation | Project structure, design system, installable landscape PWA, riding screen with media player and vehicle dashboard on mock data | in progress |
| 2 | 3D mapping prototype | Provider decision from a written spike, realistic 3D environment, third-person camera, rider and scooter, holographic route corridor, proven smooth on a mid-range Android phone | planned |
| 3 | GPS and navigation | Live GPS, heading and position smoothing, route calculation, turn-by-turn, recalculation, scooter-aware routing | planned |
| 4 | Speed zones | Geographic speed-zone data, road limit datasets, custom path zones, moderation tools, personal overrides, visualisation | planned |
| 5 | Vehicle integration | Bluetooth research, Web Bluetooth investigation, vehicle abstraction, first vehicle adapter, GPS fallback | planned |
| 6 | Supporting platform features | Accounts, vehicle management, route planner, trip history, settings, community contributions, deployable by anyone with their own backend | planned |
| 7 | Expo application | Native app reusing the shared logic, native Bluetooth and background location, matching the PWA | planned |
| 8 | Refinement | Rendering optimisation, map loading, offline behaviour, device testing, reliability and battery efficiency | planned |

## Milestone 1

An installable PWA prototype with a realistic 3D environment, a third-person rider and scooter, a glowing navigation corridor, floating directional indicators, a left-turn instruction, speed and trip information, battery and range, a media player, an End Trip button, simulated GPS movement and simulated vehicle telemetry. It does not include real Bluetooth or a routing engine. Its job is to prove that the immersive experience works in an installable PWA on a modern Android phone.

The detailed task list is in [AGENT_BRIEF.md](AGENT_BRIEF.md).
