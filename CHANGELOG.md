# Changelog

All notable changes to this project are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/) once it reaches a first release.

## [Unreleased]

### Added

- Project foundations: Apache 2.0 licence, README, contribution guide, code of conduct, security policy, issue and pull request templates, CI, Dependabot configuration and project documentation.
- Project structure: pnpm workspace with a Next.js App Router web app (`apps/web`) and shared packages `core`, `vehicle`, `map-provider` and `ui-tokens`, with strict TypeScript, ESLint, Prettier and Vitest. Pinned Node.js 22 and pnpm with a committed lockfile.
- Design system: dark glass tokens with electric blue and cyan accents, exposed as TypeScript values, CSS variables and a Tailwind theme. Documented in `docs/DESIGN_SYSTEM.md`.
- Placeholder home page with the app name, a safety notice and a link to the source code. Runs with no keys and makes no network calls.
- Read-only vehicle interface and map provider interface types, with no implementations yet.
- Docs: `docs/ARCHITECTURE.md`, run-locally steps in the README and `docs/DEPLOYING.md`, a proposed self-host path (static export), and dependency licences in `docs/THIRD_PARTY.md`.
- Simulation layer: a simulated GPS in `@waylit/core` that follows an original demo route with smoothing, playback speed, pause and resume and an injected clock, a mock Segway Ninebot MAX G3 telemetry adapter in `@waylit/vehicle` (battery drain, range, trip distance and duration, 25 km/h default limit, vehicle speed separate from GPS speed) with a GPS fallback selector, and a mock media player model with invented tracks and generated artwork, wired to the browser Media Session API with a Web Audio tone engine and a `useMockMedia` hook in `apps/web`. No new dependencies.
- Optional `NEXT_PUBLIC_WAYLIT_SOURCE_URL` so forks can point the source link at their own repository.
- PWA shell: web app manifest (standalone, landscape, design token colours), original app icons generated by a dependency free script, a hand written service worker with versioned caches and an offline page, an install button and fallback hint on the start screen, an update prompt, safe area handling, a rotate prompt in portrait on the ride screen, an optional landscape lock after a tap in the installed app, a Screen Wake Lock hook, and a dismissible first run safety notice. A placeholder `/ride` screen shows the full screen shell and wake lock. Documented in `docs/PWA.md`, including how to test on Android Chrome over USB and the limits of a PWA.

- Riding screen (`/ride`), a floating HUD over a scene that fills the whole screen: a bare, very large vehicle speed top left with GPS speed under it, the next turn arrow, distance, street instruction, time and distance left and arrival beside it. Local time, mock temperature, a connectivity dot and a round plain SVG minimap (route line, position dot and a clearly visible heading cone, no map tiles) at top right. One joined glass dock along the bottom: the media player (wired to the shared `MediaPlayer` and the Media Session API) on the left, the vehicle dashboard (battery, range, trip distance and time) and End trip on the right. The centre is a dark gradient kept free for the 3D scene, and a reserved, darker credits strip below the dock that nothing overlaps. Above 8 km/h the media controls and End trip need a short hold. Dock panels are more solid in daylight and more see-through at night.
- End trip stops the simulation and the media, releases the wake lock and shows a trip summary (distance, duration, average speed) with Start new trip.
- Route progress in `@waylit/core` (`projectOntoRoute`, `computeProgress`), GPS distance integration (`GpsDistanceIntegrator`), HUD number formatting, and `MediaPlayer.stop()`. `TripTracker` and `isTelemetryStale` in `@waylit/vehicle`: trip distance and duration fall back to GPS when scooter telemetry is missing or stale, without jumps.
- Simulation dev controls (playback speed, lose scooter data) shown in development builds, and in production only with `?dev=1`.
- Fluid riding screen type sizes (`speed`, `hudTurn`, `hudLg`, `hudDock`, `hudMd`, `hudSm`), a `tight:` variant for very short landscape screens, and new original screenshots of the HUD in `docs/images`.
- Hold to press feedback that does not rely on animation: a ring track and a filled held state with a "Keep holding" caption on every guarded control, which also work with reduced motion.

### Changed

- Design tokens: near black surfaces, soft cyan (`#5fc8e8`) as the only accent, muted greys, a dark red set used only by End trip, and flat translucent panels about 85 percent opaque with night and daylight fills. The second blue (`volt`), the glass sheen, the blue glows, `glassStrong` and `displaySm` are removed, and the minimum touch target is 44 px. The home page and offline page follow the new palette. The app icon keeps its own brand colours.
- The credits strip no longer shows placeholder text to riders. It stays empty in production, with a faint label only in development builds or with `?dev=1`.
- The ride screen now keeps the screen awake only while a trip is running, and releases it on End trip.
- Media Session: artwork is also offered as PNG (SVG is not guaranteed to show in media notifications), and the `seekto` action is handled. `useMockMedia(active)` stops sound and clears the session when the trip ends.
- Public project brief mirror updated for the model policy and the mapping provider decision (CesiumJS with Google Photorealistic 3D Tiles as primary, MapLibre GL JS on OpenFreeMap as fallback).
- CI uses the Node.js version from `.nvmrc` and also checks formatting. Dependabot now watches npm dependencies.

### Fixed

- Trip distance and time no longer lose the stale window when scooter telemetry drops out. `TripTracker` remembers where GPS and the ride clock were at the last new vehicle sample and backfills from GPS when telemetry goes stale or returns.
- The trip summary note says whether distance came from GPS, from a mix of the scooter and GPS, or only from the scooter, using the whole trip instead of the last source.
- The minimap heading cone was nearly invisible. It is now a wedge with a gradient fill and an outline.
