# Getting help

Waylit is a volunteer-run, pre-alpha project, so support is best effort.

- **Questions and ideas:** use GitHub Discussions on this repository once enabled.
- **Bugs and feature requests:** open an issue and choose the matching template.
- **Security problems:** follow [SECURITY.md](SECURITY.md). Do not post them publicly.
- **Setup or deployment trouble:** read [docs/DEPLOYING.md](docs/DEPLOYING.md) first. If it did not work for you, open an issue. Unclear docs count as bugs.

Please never paste API keys, tokens or your real location into an issue.
